# Changelog

## 0.5.0 - 2026-10-14

- Add the optional `stippleLayout` setting with the backward-compatible
  `seeded` default and a seamless regular `staggered` layout.
- Preserve `stippleLayout` in runtime options, style metadata, parsers,
  serializers, and the v1 metadata schema.
- Add the browser-only `tileToDataUrl` helper for rendering a `TileImage` as a
  PNG or another canvas-supported data URL.
