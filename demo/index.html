SVG fill (organic patterns)

Rasterized once via the browser's native SVG renderer, then scattered with seeded rotation/scale jitter into a large seamless meta-tile — avoids the "wallpaper" look you'd get tiling a single small SVG stamp.

Tinted background (under the pattern)
Outline (line)

Native line-dasharray expression — no canvas involved, stays a plain declarative style property.

Point icons (SVG)

The SVG is rasterized once via addSvgIcon; the scale slider drives the symbol layer's native icon-size, no re-rasterization needed.

The geometric pattern's parameters (angle, density, weight) are baked into a canvas image, not the style.json. In production, call installPatternFills(map, style) from the maplibre-pattern-fills package after the style loads — it regenerates the exact same texture from the enhanced:pattern metadata.
