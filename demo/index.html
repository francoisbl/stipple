SVG fill (organic patterns)

A repeating texture always clips hard at the polygon boundary — any stamp whose center falls near the edge shows only its overlapping part. This mode instead places whole icons only where they fit entirely inside the shape, leaving a clear margin near the edge instead of a cut one.

Rasterized once via the browser's native SVG renderer, then scattered with seeded rotation/scale jitter into a large seamless meta-tile — avoids the "wallpaper" look you'd get tiling a single small SVG stamp.

Point icon (SVG)

One whole icon per point feature — rasterized once via addSvgIcon, scale driven by native icon-size. No scattering/tiling involved, that's a polygon-fill concept.

Export always reflects the single geometry type selected above — polygon fill, line style, or point icon — so it's always clear what you're shipping.
